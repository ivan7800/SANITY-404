# SANITY-404 1.0 · Windows x64

1. Extrae todo `SANITY-404-Windows-x64.zip` en una carpeta de tu elección. Mantén juntos `game\`, `sanity404-server.exe` y el lanzador.
2. Haz doble clic en `INICIAR-SANITY-404.bat`. Se abrirá el navegador predeterminado en `http://127.0.0.1:40404/`.
3. Mantén abierta la ventana del lanzador mientras juegas. Pulsa Ctrl+C y confirma el cierre para detener el servidor.

No se necesitan Node.js, Electron, Python, npm, Git, permisos de administrador ni Internet después de la descarga. Se necesita un navegador moderno con WebGL. Si no se abre, visita la URL anterior manualmente.

Las partidas se guardan en el almacenamiento local del navegador para ese origen. Usa el mismo navegador y perfil para continuar. Evita el modo privado y no borres los datos del sitio. Si el puerto fijo está ocupado por otra aplicación, se mostrará un error; el juego no cambiará de origen.

Los hashes de los archivos extraídos están en `SHA256SUMS.txt` y el inventario en `MANIFIESTO_DISTRIBUCION.json`.
